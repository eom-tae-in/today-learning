## 📌 오늘 학습 계획

1. **Stream API 기반 Post CRUD 마무리**
    - `filter()`, `map()`, `findFirst()` 등을 활용해 게시글을 조회한다.
    - `Optional`로 조회 결과가 없는 경우를 안전하게 처리한다.
    - 게시글 등록·조회·수정·삭제의 전체 흐름을 점검한다.
2. **ORM 개요 학습**
    - ORM의 개념과 필요한 이유를 이해한다.
    - 자바 객체와 관계형 데이터베이스 테이블의 차이를 확인한다.
    - ORM이 객체와 테이블 사이의 변환을 어떻게 지원하는지 정리한다.
3. **파일 입출력과 직렬화 학습**
    - 입력 스트림과 출력 스트림의 역할을 구분한다.
    - 바이트 스트림과 문자 스트림의 차이를 이해한다.
    - 파일에 데이터를 쓰고 다시 읽는 기본 코드를 실습한다.
    - `Serializable`을 이용해 객체를 저장하고 복원한다.
4. **정규표현식 개념 및 실습**
    - 문자 클래스, 수량자 등 기본 문법을 익힌다.
    - `Pattern`과 `Matcher`의 역할과 처리 흐름을 이해한다.
    - 더미 데이터에서 원하는 값을 검증하거나 추출한다.
