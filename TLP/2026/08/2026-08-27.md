## 📌 오늘 학습 계획

1. **단일행·다중행 서브쿼리 구분**
    - 서브쿼리의 위치와 실행 흐름을 확인한다.
    - 반환되는 행의 수를 기준으로 단일행과 다중행 서브쿼리를 구분한다.
    - 서브쿼리의 결과에 따라 외부 쿼리에서 사용할 연산자가 달라지는 이유를 확인한다.
2. **다중행 서브쿼리 연산자 학습**
    - 다중행 결과를 처리할 때 사용하는 `IN`, `ANY`, `ALL`의 의미와 사용 방식을 구분한다.
    - 같은 다중행 결과에 각 연산자를 적용하여 조건과 조회 결과의 차이를 비교한다.
3. **서브쿼리 실습**
    - 단일행과 다중행 서브쿼리를 직접 작성하고 실행 결과를 확인한다.
    - 다중행 서브쿼리에 `IN`, `ANY`, `ALL`을 적용한 뒤 예상 결과와 실제 결과를 대조한다.
    - 잘못된 연산자를 사용했을 때 발생하는 문제를 확인하고 쿼리를 수정한다.
4. **DDL 학습**
    - `CREATE`, `ALTER`, `DROP`의 역할과 사용 시점을 구분한다.
    - 테이블 생성, 구조 변경, 삭제에 필요한 DDL 문법을 작성하고 실행 결과를 확인한다.
5. **제약조건 적용**
    - `PRIMARY KEY`, `FOREIGN KEY`, `NOT NULL`, `UNIQUE`, `CHECK`의 목적과 차이를 구분한다.
    - `CREATE`와 `ALTER`를 이용하여 테이블에 제약조건을 설정하는 방법을 확인한다.
    - 각 제약조건을 위반하는 데이터가 제한되는지 실행 결과로 검증한다.
