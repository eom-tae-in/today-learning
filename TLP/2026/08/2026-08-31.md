## 📌 오늘 학습 계획

1. **DB 학습 내용 마무리**
    - 지금까지 학습한 DML·DDL, 제약조건, JOIN, 서브쿼리와 Top-N 관련 내용을 중심으로 DB 학습 흐름을 정리한다.
    - 각 SQL 문법의 사용 목적과 쿼리 실행 결과를 다시 확인하며 혼동되는 부분을 마무리한다.
    - DB가 데이터를 저장하고 애플리케이션의 요청에 따라 조회·변경 결과를 제공하는 역할을 확인한다.
2. **React–Spring Boot–DB 구조 파악**
    - React는 화면과 사용자 입력을 담당하고, HTTP 요청을 통해 Spring Boot와 통신한다는 구조를 확인한다.
    - React가 DB에 직접 접근하지 않고 Spring Boot가 JPA·JDBC를 통해 원격 DB에 접근하는 이유를 정리한다.
    - 요청과 응답이 `React → Spring Boot → DB → Spring Boot → React` 순서로 이동하는 흐름을 연결한다.
3. **Spring Boot와 내장 Tomcat 구조 확인**
    - Spring Boot와 실제 HTTP 요청을 처리하는 내장 Tomcat의 역할을 구분한다.
    - Coyote가 HTTP 요청을 수신하고 Catalina가 Servlet을 실행·관리하는 관계를 확인한다.
    - `DispatcherServlet`이 Catalina가 관리하는 Servlet이라는 점을 중심으로 포함 관계를 정리한다.
4. **DispatcherServlet의 요청 처리 흐름 학습**
    - `DispatcherServlet`이 Spring MVC의 프런트 컨트롤러로서 요청을 가장 먼저 받는 이유를 확인한다.
    - 요청이 `DispatcherServlet → Controller → Service → Repository → DB` 순서로 처리되는 흐름을 정리한다.
    - DB 조회 결과가 DTO와 JSON 응답으로 변환되어 React에 반환되는 과정을 확인한다.
5. **Jasper와 React 기반 REST API 비교**
    - Jasper가 JSP를 Servlet으로 변환하고 컴파일하는 JSP 엔진이라는 역할을 확인한다.
    - JSP 방식에서는 Jasper가 HTML 생성 과정에 참여하지만, React 기반 REST API에서는 일반적으로 Jasper가 사용되지 않는다는 차이를 구분한다.
    - JSON을 반환하는 React·REST 구조와 HTML을 반환하는 JSP 구조의 요청 처리 경로를 비교한다.
