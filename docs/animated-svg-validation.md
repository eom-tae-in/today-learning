# 애니메이션 SVG 검증 기록

검증일: 2026-10-20. 브라우저: 로컬 Google Chrome.

## 실행 결과

- `npm test`: 75개 통과, 실패 없음.
- `npm run build`: Astro 검사 오류 없음, 53개 정적 페이지 생성.
- `SVG_QA_BROWSER=chrome npm run test:svg`: 통과.
- `git diff --check`: 통과.
- 독립 최종 검토: PASS / APPROVE. 완료된 CSS 효과의 상태 유지 문제를 해결한 것으로
  확인했고 검토자가 브라우저 회귀 검사와 75개 테스트를 별도로 재실행했다.

브라우저 회귀 검사는 완료된 1회 CSS 애니메이션, 반복 애니메이션, 동일 요소에서
이름이 중복되는 애니메이션을 함께 넣어 확대·닫기 시 상태 유지와 재시작을 확인한다.
다이얼로그가 닫힐 때 CSS 애니메이션이 취소되는 문제도 이 검사에 포함된다.

## 실제 화면 검증

- 정적 예제 페이지에서 390px·1440px, 밝은·어두운 테마를 확인했다.
- 시간 경과에 따른 SMIL 이동, CSS 단계 강조와 결과의 순차 등장을 확인했다.
- 재생·일시정지·처음부터 재생, 확대·Escape 닫기와 재생 위치 유지를 확인했다.
- 모바일 확대에서는 실제 그림 크기가 커지고 그림 영역 안에서 스크롤된다.
- 모션 감소 설정에서 자동 재생하지 않으며 명시적 재생은 가능하다.
- `/today-learning/attachments/examples/build-flow.svg` 요청이 200으로 응답했다.
- 실제 `/records/2099-01-01/` 경로에 임시 TIL을 넣어 중복 SVG 격리,
  소주제 접기·화면 밖에서 일시정지, 사용자 일시정지 유지,
  일반 이미지 로딩·클릭 확대를 확인했다. 임시 TIL과 posts.json 변경은 복원했다.

## 검증 한계

Obsidian 앱, Safari, Firefox, 실제 휴대폰과 GitHub Pages 배포는 직접 검증하지 않았다.
Obsidian은 같은 SVG 파일을 이미지로 참조하며 사이트 전용 재생 버튼은 제공되지 않는다.
빌드에는 기존 대형 JavaScript 청크 경고와 Obsidian CommonJS 스크립트의 변환 힌트가 남는다.
커밋·푸시·배포는 실행하지 않았다.
