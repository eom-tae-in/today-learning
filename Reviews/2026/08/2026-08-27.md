# 🤖 AI 학습 리포트

2026.08.27

> 오늘의 TLP와 TIL을 바탕으로 학습 흐름을 간단히 리포트합니다.

## 🧭 종합

서브쿼리 연산자와 DDL·제약조건 계획을 중심으로 Top-N과 조인 실행 관점까지 확장해 정리했다.

## 📝 요약

계획한 단일·다중행 서브쿼리, IN·ANY·ALL, CREATE·ALTER·DROP, 주요 제약조건이 TIL의 표와 예제로 이어졌고 NULL, 윈도우 함수, Driving/Driven Table 내용이 추가됐다.

## 📚 주요 학습

- 반환 행 수 기준 단일행·다중행·상관 서브쿼리 구분
- IN, ANY, ALL, EXISTS의 조건 판단 방식과 NULL 비교 주의점
- ORDER BY, LIMIT, 윈도우 함수 기반 전체·그룹별 Top-N 조회
- Driving Table과 Driven Table의 역할 및 인덱스 탐색 관점
- CREATE, ALTER, DROP과 PK·FK·NOT NULL·UNIQUE·CHECK 제약조건

## 👍 잘한 점

- TLP의 예상 어려움이었던 ANY와 ALL 혼동을 경계값 표와 '하나라도/모두' 기준으로 풀어냈다.
- 서브쿼리에서 Top-N, 조인 실행 관점, DDL·제약조건으로 이어지는 흐름을 단계적으로 남겼다.

## 🔧 보완할 점

- 서브쿼리 실습에서 예상 결과와 실제 결과를 대조한 기록은 보이지 않는다.
- 제약조건 위반 데이터를 입력해 제한 여부를 확인한 결과는 남아 있지 않다.
