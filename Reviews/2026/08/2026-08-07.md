# 🤖 AI 학습 정리

2026.08.07

> 오늘의 TLP와 TIL을 바탕으로 오늘 학습을 한 번 정리해 봅니다.

## 종합

React 블로그 토이프로젝트에서 게시글 CRUD, 상세 조회, 댓글 1:N 구조를 구현하며 URL, API, State, UI 흐름을 정리했다.

## 잘 이어간 점

- TLP에서 계획한 useEffect 데이터 조회와 useParams 기반 상세 조회를 URL → API → State → UI 흐름으로 연결해 남겼다.
- 댓글 생성, 수정, 삭제를 POST, PATCH, DELETE와 spread, map, filter 상태 갱신 패턴으로 비교해 정리했다.

## 다음에 다듬을 점

- TLP의 React Router DOM 복습 항목 중 useNavigate, Link, Navigate는 TIL에서 상대적으로 짧게 다뤄졌다.
- TLP에 있던 알고리즘 1문제 풀이 결과는 TIL에 남지 않았다.

## 다음 액션

- useNavigate, Link, Navigate와 useParams, useSearchParams, useLocation의 역할 차이를 다시 비교한다.
