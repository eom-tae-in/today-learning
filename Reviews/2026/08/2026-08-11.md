> 오늘의 TLP와 TIL을 바탕으로 오늘 학습을 한 번 정리해 봅니다.

## 종합

TLP의 Java 개발 환경 구성부터 타입, 메서드, 패키지, 객체 생성 계획이 TIL의 실습과 흐름 정리로 이어졌다.

## 잘 이어간 점

- JDK → javac → .class → JVM 실행 흐름을 코드와 함께 남기며 환경 구성 목표와 연결했다.
- `클래스 → new → 생성자 → 객체` 흐름 안에서 생성자 오버로딩을 함께 다뤄 객체 생성 과정을 연결해 정리했다.

## 다음에 다듬을 점

- 기본 타입과 참조 타입이 메모리에서 다르게 다뤄지는 부분은 복습 항목으로 남았다.
- `static` 메서드와 인스턴스 메서드의 차이는 다음 학습 주제로 이어졌다.

## 다음 액션

- Java 기본 문법을 활용해 여러 형태의 클래스를 직접 작성해본다.
- `static`과 인스턴스의 차이를 학습하고 생성자 호출, `this`의 역할과 함께 다시 본다.
