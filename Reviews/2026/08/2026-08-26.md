# 🤖 AI 학습 리포트

> 오늘의 TLP와 TIL을 바탕으로 학습 흐름을 간단히 리포트합니다.

## 🧭 종합

집계 함수와 GROUP BY에서 시작해 JOIN, OUTER JOIN, NULL 처리, JOIN 후 집계까지 흐름을 이어갔다.

## 📝 요약

TLP의 집계와 JOIN 목표가 TIL에서 함수별 NULL 처리, WHERE와 HAVING, ON과 WHERE 조건 위치, COUNT 방식 비교로 연결됐다.

## 📚 주요 학습

- COUNT, SUM, AVG, MAX, MIN의 역할과 NULL 처리
- GROUP BY 기준 컬럼과 SELECT 절에 작성할 수 있는 값
- WHERE와 HAVING의 적용 시점 차이
- INNER JOIN과 LEFT JOIN, RIGHT JOIN의 결과 차이
- LEFT JOIN 후 COUNT(e.emp_id)로 직원이 없는 부서 0명 집계

## 👍 잘한 점

- 학습 흐름을 집계 함수에서 JOIN 후 GROUP BY까지 단계적으로 연결해 기록했다.
- LEFT JOIN의 조건 위치와 COUNT(*) 차이를 예제 결과로 비교해 남겼다.

## 🔧 보완할 점

- 다대다 관계를 중간 테이블로 연결하는 실제 JOIN 쿼리 기록은 남지 않았다.
