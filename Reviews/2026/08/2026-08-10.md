## 종합

React의 State 변경과 Re-rendering 흐름을 Kakao Map API, Weather API, Geolocation, fetch 연동 실습으로 이어갔다.

## 잘 이어간 점

- 현재 위치의 latitude와 longitude를 Kakao Map의 지도·Marker 표시와 Weather API 요청에 함께 사용하는 흐름으로 정리했다.
- API Key, 플랫폼 설정, SDK 로드, Console과 Network 확인까지 API 연동 과정의 단계별 점검 순서를 남겼다.

## 다음에 다듬을 점

- Kakao Map API 설정에서 JavaScript Key, Web 플랫폼, 도메인 등록, API 사용 설정 흐름이 헷갈렸다고 남겼다.
- Network에 나타나는 SDK 내부 리소스 요청과 직접 작성한 API 요청을 구분하기 어려웠다고 정리했다.

## 다음 액션

- useEffect와 Re-rendering 실행 흐름을 다시 복습하고 Open API 요청에서 State와 UI까지 이어지는 코드를 보지 않고 다시 작성해본다.
- API 요청 실패에 대한 try/catch 처리와 위치 권한 거부 상황 예외 처리를 추가한다.
