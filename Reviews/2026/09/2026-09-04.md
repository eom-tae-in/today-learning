# 🤖 AI 학습 리포트

2026.09.04

> 오늘의 TLP와 TIL을 바탕으로 학습 흐름을 간단히 리포트합니다.

## 🧭 종합

게시글·댓글 처리 흐름을 MyBatis 매핑부터 Spring AOP, Filter·Interceptor, React 연동까지 단계별로 이어 정리했다.

## 📝 요약

TLP에서 잡은 관계 매핑, 트랜잭션 프록시, 웹 요청 처리 위치, 댓글 등록 흐름을 TIL에서 표와 예제 흐름으로 연결했다.

## 📚 주요 학습

- JOIN 결과를 부모·자식 식별 컬럼과 collection으로 객체 목록에 매핑하는 MyBatis 관계 매핑
- DB 결과 매핑, DTO 변환, Jackson JSON 직렬화·역직렬화의 단계 구분
- Spring AOP 프록시 경유 여부와 내부 호출에 따른 Advice·@Transactional 적용 차이
- Filter, DispatcherServlet, Interceptor, Controller의 요청 처리 위치와 중단 조건
- React 댓글 등록에서 CORS, HTTP 응답, JSON 파싱, 상태 갱신, DB 저장 결과를 분리해 보는 기준

## 👍 잘한 점

- JOIN 행, DTO 변환, JSON 응답, React 상태 갱신을 하나의 요청 흐름으로 묶어 각 단계의 책임을 분리했다.
- 내부 호출과 기존 트랜잭션 참여를 구분해 @Transactional 적용 여부를 단순한 애너테이션 존재로 판단하지 않도록 정리했다.

## 🔧 보완할 점

- TIL의 코드와 흐름은 설명용 예제라고 명시되어 있어, 실제 프로젝트에서 Network 응답, DB 재조회, 화면 갱신을 대조한 기록은 남지 않았다.
