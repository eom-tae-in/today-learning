# 🤖 AI 학습 리포트

2026.09.02

> 오늘의 TLP와 TIL을 바탕으로 학습 흐름을 간단히 리포트합니다.

## 🧭 종합

Swagger 명세 확인에서 프론트·백엔드 연결, CORS 원인 구분과 개선 내용까지 이어갔다.

## 📝 요약

TLP의 API 명세 대조와 CORS 점검 계획이 TIL에서 요청·응답 흐름, Origin 비교, Spring CORS 설정 기준으로 연결됐다.

## 📚 주요 학습

- Swagger 명세의 경로·메서드·입력 위치·응답 구조 확인
- Spring MVC Controller 응답 DTO와 JSON 직렬화 흐름
- 프론트 fetch 응답 처리와 화면 상태 갱신 과정
- Origin 구성 요소와 CORS 허용 헤더의 역할
- MyBatis Mapper XML, namespace, SQL id, @Param 연결

## 👍 잘한 점

- API 실행 오류, CORS 응답 접근 제한, 프론트 데이터 처리 오류를 구분하는 기준을 표로 정리했다.
- TLP의 복습 항목이 요청 수신 방식, MyBatis 매핑, 응답 분기, 애노테이션 역할 정리로 이어졌다.

## 🔧 보완할 점

- 실습 기록에는 연결과 CORS 개선 사실이 남아 있지만, 실제 변경한 CORS 설정과 개선 전후 응답 상태·화면 결과는 구체적으로 드러나지 않았다.
