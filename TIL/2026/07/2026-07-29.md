### 🎯 액션 플랜

- React에서 `fetch()` 또는 `axios`를 이용한 API 호출 과정을 실습하며 복습한다.

## 📚 배운 점

### 💡 배움

- HTML은 화면의 구조, CSS는 디자인, JavaScript는 화면의 동작과 서버 통신을 담당한다.
    
- Full Browsing은 HTML 문서를 주고받으며 페이지 전체를 새로고침하고, SPA는 JavaScript가 REST API와 통신하여 JSON을 받아 필요한 화면만 갱신한다.
    
- DOM은 브라우저가 HTML을 객체 형태로 표현한 구조이며, JavaScript는 DOM을 조작하여 화면을 변경한다.
    
- Form, JSON, REST API가 각각 어떤 상황에서 사용되는지와 데이터 전달 방식(Path Variable, Query String, JSON Body)을 정리했다.
    

### 🌱 의미

- 개별 문법을 배우는 것보다 웹이 어떤 흐름으로 동작하는지를 이해하는 것이 중요하다는 점을 느꼈다.
    
- 앞으로 React와 Spring을 학습할 때도 오늘 정리한 전체 흐름을 기반으로 학습하면 개념을 더 쉽게 연결할 수 있을 것 같다.
