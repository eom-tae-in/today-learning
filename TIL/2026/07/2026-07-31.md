## 📚 배운 점

### 💡 배움

- DOM은 `innerHTML`을 이용한 문자열 방식과 `createElement()`를 이용한 DOM API 방식으로 생성할 수 있으며, 상황에 따라 적절한 방식을 선택해야 한다.
- 이벤트는 브라우저에서 발생하는 동작이며, 이벤트 핸들러를 통해 원하는 로직을 실행할 수 있다.
- Promise는 비동기 작업의 상태와 결과를 관리하며, `async/await`는 이를 더 읽기 쉽게 작성하기 위한 문법이다.
- `fetch`와 Axios는 모두 Promise 기반의 HTTP 통신 도구이지만 JSON 처리 방식과 오류 처리 방식에서 차이가 있다.
- SPA는 페이지 전체를 새로고침하지 않고 비동기 통신으로 필요한 데이터만 받아 화면 일부를 갱신한다.
- 미디어 쿼리와 `flex-wrap`을 이용해 다양한 화면 크기에 대응하는 반응형 웹을 구현할 수 있다.

### 🌱 의미

오늘 학습을 통해 DOM 조작, 이벤트 처리, 비동기 통신, 반응형 웹이 각각 독립적인 개념이 아니라 실제 프론트엔드에서 하나의 흐름으로 연결되어 동작한다는 점을 이해할 수 있었다. React를 학습하기 전에 필요한 JavaScript 기반 동작 원리를 정리하는 시간이 되었다.
