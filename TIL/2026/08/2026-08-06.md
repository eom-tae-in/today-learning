## 🔧 개선점

### ❗ 문제

기능은 구현했지만 React Router의 내부 동작 방식과 Hook의 실행 흐름은 아직 완전히 익숙하지 않은 부분이 있었다. 또한 페이지 간 데이터가 전달되는 과정을 이해하는 데 시간이 다소 걸렸다.

### 🔍 원인

동작은 구현할 수 있었지만 라우팅과 데이터 흐름을 구조적으로 정리하는 시간이 부족했다. 개념보다 구현에 집중하면서 전체 흐름을 한 번에 연결해 보는 연습이 부족했다.

### 🎯 액션 플랜

오늘 작성한 블로그 프로젝트를 다시 구현하며 화면 이동과 데이터 흐름을 처음부터 복습한다. useEffect, useParams, useNavigate가 언제 실행되고 어떤 역할을 하는지 직접 설명할 수 있을 정도로 정리한다.
