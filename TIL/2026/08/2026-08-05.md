## 📚 배운 점

### 💡 배움

- React는 State가 변경되면 컴포넌트를 다시 실행하여 새로운 UI를 계산한다.
    
- 이벤트는 JSX에서 선언적으로 연결하며, 사용자의 입력은 이벤트 핸들러를 통해 State를 변경한다.
    
- Form은 Controlled Component 방식으로 State와 입력값을 동기화하여 관리한다.
    
- 객체와 배열 State는 직접 수정하지 않고 새로운 객체나 배열을 만들어 불변성을 유지해야 한다.
    
- SPA에서도 Session 기반 인증을 사용할 수 있으며, JWT는 API 중심의 분산 환경에서 많이 활용되는 인증 방식이라는 점을 이해했다.
