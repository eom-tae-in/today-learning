# 📚 학습 내용

## 1. 배열과 반복 순회

### 개념

배열은 같은 타입의 값을 정해진 길이만큼 하나로 묶어 관리하는 참조 타입이다.

```java
int[] scores = {90, 80, 100};

System.out.println(scores[0]); // 90
System.out.println(scores.length); // 3
```

배열의 각 요소는 `0`부터 시작하는 인덱스로 접근한다. 배열의 길이는 생성할 때 결정되며 이후 변경할 수 없다.

### `for`문과 `for-each`문

|구분|적합한 상황|
|---|---|
|일반 `for`문|인덱스가 필요하거나 특정 위치의 값을 변경할 때|
|`for-each`문|배열의 값을 처음부터 끝까지 단순히 조회할 때|

```java
int[] scores = {90, 80, 100};

for (int i = 0; i < scores.length; i++) {
    System.out.println(i + ": " + scores[i]);
}

for (int score : scores) {
    System.out.println(score);
}
```

> `for-each`문의 반복 변수에는 배열 요소의 값이 복사되므로, 반복 변수 자체를 변경해도 원본 요소는 바뀌지 않는다.

## 2. 상속을 통한 클래스 확장

### 개념

상속은 기존 클래스의 필드와 메서드를 물려받아 새로운 클래스를 만드는 기능이다.

```text
부모 클래스
 ├─ 공통 필드
 └─ 공통 메서드
        ↓ extends
자식 클래스
 ├─ 부모에게 물려받은 기능
 └─ 자식이 추가하거나 재정의한 기능
```

자식 클래스는 `extends`를 사용해 부모 클래스를 상속한다.

```java
class Animal {
    public void sound() {
        System.out.println("동물이 소리를 낸다.");
    }
}

class Dog extends Animal {
    @Override
    public void sound() {
        System.out.println("멍멍");
    }
}
```

상속의 목적은 단순히 코드를 줄이는 것이 아니라, 공통된 특징을 부모에 정의하고 자식이 이를 구체화하도록 관계를 설계하는 데 있다.

### 핵심 포인트

- Java 클래스는 하나의 클래스만 직접 상속할 수 있다.
- 생성자와 `private` 멤버는 그대로 상속해 사용할 수 없다.
- 자식 객체를 생성하면 부모 생성자가 먼저 호출된 후 자식 생성자가 실행된다.
- 자식 클래스는 부모 메서드를 그대로 사용하거나 오버라이딩할 수 있다.

> 상속은 두 클래스 사이에 명확한 `is-a` 관계가 있을 때 사용하는 것이 적절하다.

## 3. 다형성과 메서드 오버라이딩

### 개념

다형성은 하나의 부모 타입으로 여러 종류의 자식 객체를 다룰 수 있는 성질이다.

```java
Animal animal = new Dog();
animal.sound(); // 멍멍
```

위 코드에서 변수의 타입은 `Animal`이지만 실제 객체는 `Dog`이다.

```text
부모 타입 변수
      ↓ 참조
자식 객체
      ↓ 메서드 호출
자식이 재정의한 메서드 실행
```

### 다형성의 구분

|구분|핵심 내용|
|---|---|
|변수의 다형성|부모 타입 변수로 자식 객체를 참조|
|메서드의 다형성|오버라이딩된 메서드는 실제 객체를 기준으로 실행|
|매개변수의 다형성|부모 타입 매개변수로 여러 자식 객체를 전달받음|

```java
class Animal {
    public void sound() {
        System.out.println("동물이 소리를 낸다.");
    }
}

class Dog extends Animal {
    @Override
    public void sound() {
        System.out.println("멍멍");
    }
}

class Cat extends Animal {
    @Override
    public void sound() {
        System.out.println("야옹");
    }
}

public class Main {
    public static void makeSound(Animal animal) {
        animal.sound();
    }

    public static void main(String[] args) {
        Animal[] animals = {
            new Dog(),
            new Cat()
        };

        for (Animal animal : animals) {
            makeSound(animal);
        }
    }
}
```

```text
Dog 객체 ─┐
          ├─ Animal 매개변수로 전달
Cat 객체 ─┘
                 ↓
        실제 객체의 sound() 실행
```

### 핵심 포인트

> 접근 가능한 멤버는 참조 변수의 타입을 기준으로 결정되지만, 오버라이딩된 인스턴스 메서드는 실제 객체를 기준으로 실행된다.

부모 타입 변수로 자식 객체를 참조하면 부모 타입에 선언된 멤버만 직접 사용할 수 있다. 자식에만 존재하는 멤버가 필요하다면 타입 확인 후 다운캐스팅해야 한다.

## 4. `final`을 통한 확장 제한

|사용 위치|의미|
|---|---|
|`final class`|다른 클래스가 상속할 수 없음|
|`final method`|자식 클래스에서 오버라이딩할 수 없음|

```java
final class Utility {
}

// class CustomUtility extends Utility {} // 상속 불가
```

```java
class Parent {
    public final void run() {
        System.out.println("실행");
    }
}

class Child extends Parent {
    // run()을 오버라이딩할 수 없음
}
```

> `final`은 변경되거나 확장되면 안 되는 클래스와 메서드의 설계 의도를 코드에 명확하게 표현한다.

# 🔄 함께 복습한 내용

- `static` 멤버는 클래스에 속하고, 인스턴스 멤버는 생성된 객체에 속한다.
- 중첩 반복문에서 `break`와 `continue`는 기본적으로 가장 가까운 반복문에 적용된다.
- Stack에는 메서드 실행 정보와 참조값이, Heap에는 객체와 배열이 저장된다.
- GC는 Heap의 객체가 GC Root로부터 도달 가능한지를 기준으로 정리 대상을 판단한다.
